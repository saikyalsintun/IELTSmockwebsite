IELTS Listening Practice — New Test

Files:
- index.html
- style.css
- script.js
- audio/part1.mp3 ... audio/part4.mp3

Put the four recordings in the audio folder using those exact names. You can also use the Choose audio file button for a local recording.

The test has Questions 1–40, automatic marking, answer tracking, score /40, approximate IELTS band, part-by-part scores, and question review.

This is an independent IELTS-inspired practice interface, not an official IELTS test.
