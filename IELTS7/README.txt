Answers are stored locally in the browser. The site includes live answer tracking, 30-minute timer, automatic marking, IELTS Listening band estimate, part scores, review, and Print / Save PDF.

This is an independent IELTS-style practice interface, not an official IELTS test.

Answer key loaded exactly as supplied. Q20 requires BOTH answers (Yen and Australian dollar) for its single mark. Questions 28–30 are scored individually as D, E, F while displayed as one choose-three group.

Submission behavior:
- Finish Test can be clicked at any time, even if some questions are unanswered.
- Unanswered questions are automatically marked incorrect.
- The results page shows unanswered questions as "—" and displays the correct answer.
- There is no requirement to answer all 40 questions before submitting.
