IELTS Listening Practice Website

This package contains all four parts and Questions 1–40 based on the Part 1–4 material supplied by the user.

Files:
- index.html
- style.css
- script.js
- audio/part1.mp3
- audio/part2.mp3
- audio/part3.mp3
- audio/part4.mp3

Add the four audio files to the audio folder using exactly those filenames. Alternatively, use “Choose audio file” in the browser.

The site includes:
- Part 1–4 question layouts
- Text-answer blanks
- Multiple choice questions
- Questions 6–8: choose THREE
- Questions 24–28: choose FIVE
- Automatic marking after Finish test
- Score /40 and approximate Listening band
- Correct answers shown for wrong questions
- 30-minute timer
